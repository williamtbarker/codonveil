# Security policy

CodonVeil is an offline scientific utility and should never require credentials or network access at runtime.

Please report suspected vulnerabilities privately through GitHub's security-advisory interface after publication. Do not include confidential sequence data, credentials, or protected health information in a report.

Version 0.1.x receives best-effort security fixes. CodonVeil is not a clinical device and must not be used as the sole basis for health or public-health decisions.
